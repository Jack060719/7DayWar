## 實際涵蓋

技能列表使用實際 MP 成本與突破機率；重複技能書仍可嘗試突破，先確認耗書與失敗不退。四角色可建立、切換、保存本機隊伍，另三角確實進入 renderer；重開保留四角與隊伍設定。每名角色的離線摘要分列。

友方變身只列出目標自己的可用形態；邀請不扣 MP／HP／材料，只有目標能接受。接受後正常付費並只改目標；拒絕、死亡、離房、跨圖或失去距離取消。客端自行傳 consent:true 不會取得權限。原生案例以兩名本機角色切換同意；家庭房協定由總整合另驗。

交易面板只編輯自己的物品與金幣，對方內容唯讀。保存變更、同版本雙方確認後才完成；未保存輸入、陳舊版本及重複點擊都有保護。原生本機案例交換 17 金幣，雙方保存並重開確認；跨手機暫鎖／原房主核對由總整合另驗。交易暫鎖狀態在行囊與交易面板顯示。

舊寵物先選性別／常見個性並預覽，確認後才升級；背包保留物品 UID。繁殖先保存結果再提交，重開可完成已封存結果；雙點只產生一隻子代、一次收據，兩名親代各用一次機會。面板顯示五屬性品質、出生／目前、主副個性、忠誠實際加值、繁殖次數與容量。野外寵物檢視使用已保存 traits，沒有再抽 RNG。

手機直向使用原生 modal 阻止遊戲操作，模擬與保存仍持續，回橫向保留原面板。裝備姓名與 +N 一致；未知裝備不顯示隱藏的附魔或品質。
