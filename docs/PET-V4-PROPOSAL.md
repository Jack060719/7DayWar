# 寵物 v4 試玩初版提案

狀態：**使用者已批准作為試玩初版規格；尚在實作及驗證中，本文不是完工證據。**

本提案把缺口清單已有的規則與缺少的數值分開。未找到寵物 v4 的原始五屬性物種數值附件或完整個性表；以下新增數值均是本專案的試玩建議，不是原作資料，也不是先前已確認的候選。以下試玩數值已由使用者整體批准；程式與存檔遷移仍須依本文實作並通過驗證。

## 已確認的方向與數字

- 每隻寵物有 STR、DEX、INT、MND、VIT，五項獨立生成、各自判白／藍／橘。
- 普通常見個性只有正面效果；白／藍／橘倍率為 1.0／1.2／1.5。
- 進階單型是一增一減；進階複合是兩增兩減。正面倍率為 1.6／1.8／2.0，負面倍率為 1.2／1.3／1.4。
- 同物種異性配種；LV30、LV45 各解鎖一次，一生最多兩次；禁止父母子女及共享任一父母的兄弟姊妹配種。
- 子代初始資質以父母平均值為基礎，上下浮動 10%；可突破物種初始上限，突破的屬性保持橘色。
- 每次出生固定 1/32 機率覺醒先祖血脈；主個性照常生成，副個性取自父母／祖父母已記錄的個性，效果獨立相加。
- 忠誠靠出戰時間累積，飢餓停止累積，死亡少量扣除；藍色括號列出增益。
- 項圈零重量、可收藏；有效 CHA 的職業加值是妖精 +12、法師 +6、黑妖 +6、騎士 +0。CHA 影響捕捉及出戰容量，不影響繁殖、遺傳或突破。

以下所有未在上述列明的門檻、公式、機率、費用、範圍與遷移方式，原屬提案，现已隨本文獲批准作試玩初版；不得改稱原作確認值。

## 3. 每項品質、成長及實際效果

令 B 為保存的出生屬性，min／max 為該物種該項範圍，R = max − min。品質只按出生值判定，升級不偷偷更換品質：

- 白：B < min + R × 0.5。
- 藍：min + R × 0.5 ≤ B < max。
- 橘：B ≥ max。子代突破者保存橘色鎖定標記，不因顯示取整掉回藍色。

白色沿用物種每級基礎成長。藍色每升一級，該屬性額外增加 R × 0.00125；橘色增加 R × 0.0025。白、藍的屬性上限是該物種初始 max；橘色解除這個上限。

計算中的屬性不逐級取整：A = B + R × 品質成長率 × (等級 − 1)，白／藍再以 max 封頂。存檔用出生值的萬分之一整數及版本化公式推導，避免每次重開造成小數漂移。面板顯示兩位小數；計算保留完整精度。

令 q = (A − min) / R。物理、魔法、生命及魔力係數 F(q) = clamp(0.8 + 0.4 × q, 0.5, 2.0)。普通範圍內仍是約 80%–120%，接近舊版四資質的差異。

| 屬性 | 提案效果 |
| --- | --- |
| STR | 物攻 = floor((基礎物攻 + 0.5 × (等級−1)) × F(q))，最低 1；近戰技能若使用物理攻擊，也套同一係數，不另疊第二次。寵物背包容量 = floor(20 + 4 × A)。 |
| DEX | 攻擊及移動速度係數 = clamp(0.9 + 0.2 × q, 0.75, 1.35)，間隔除以係數；物理命中增量為 4 × (q−0.5) 個百分點，DG 增量為 2 × (q−0.5) 個百分點。這兩項增量各限制在 −5 至 +10 百分點。 |
| INT | 既有魔法傷害、治療量及數值型技能效果乘 F(q)；魔法不加物理命中抽樣，仍受原有 MR、元素抗性與視線影響。持續秒數、耗魔及冷卻不乘這個係數。 |
| MND | MP 上限 = floor((基礎 MP + 每級 MP × (等級−1)) × F(q))；貓、兔的原有每 8 秒 1 MP 回復速率也乘 F(q)。MR = clamp(物種 MR + 4 × (q−0.5), 0, 100)。原本 MP 上限 0 的物種不因此免費得到法術。 |
| VIT | HP 上限 = floor((基礎 HP + 每級 HP × (等級−1)) × F(q))，最低 1；AC = 8 − floor((等級−1)/5) − floor(4 × (q−0.5))。新增每秒 max(0,q−0.5)/20 HP 的微量自然回復，最高每秒 0.1 HP。 |

自然 HP 回復限存活、出戰、同圖、食物大於 0 且脫戰至少 8 秒；回復小數留帳，累積整數才補血。進出光環、升級或切換面板不免費補滿 HP／MP。MP 自然回復沿用既有戰鬥可回魔方式。

STR 所需寵物背包是另一個需實作的介面：建議初版只允許主人手動放入／取出自己的普通物品、裝備及卷軸，不接受寵物項圈、不自動撿物、不自動用藥。拒絕放入後超重的轉移，不另加移速懲罰；寄放或死亡仍保存其中物品。這個背包目前不存在，不能只顯示容量就宣稱完成。

### 橘色專屬光環

寵物存活、出戰、食物大於 0 且未超出主人等級／容量時啟用；作用於 5 格內的主人及該主人的寵物／召喚物。同一光環重複出現只取一次，不因多寵、多玩家疊十層。

| 橘色屬性 | 光環 |
| --- | --- |
| STR | 物理伤害 +1% |
| DEX | 攻擊與移動速度 +1% |
| INT | 魔法傷害與治療量 +1% |
| MND | MR +1 個百分點 |
| VIT | 最大 HP +1% |

跨家庭玩家不共享本初版光環；這是控制初版增益範圍的提案，需使用者同意。

例：LV1 狼的 VIT 範圍 8–16。VIT=8 時 HP=44，VIT=12 時 HP=55，VIT=16 時 HP=66，並啟用 VIT 光環。藍色 VIT 的額外成長在 LV50 約多 2.45% HP 係數，橘色約多 4.9%；不是每級多 20%。

## 4. 個性：倍率乘在明確的基準增量上

下表是「一份基準增量」。已確認的 1.0／1.2／1.5 等倍率乘這一份增量，**不是把整隻寵物能力直接乘 1.5 或 2 倍**。

| 抽取項目 | 一份基準增量 |
| --- | --- |
| 近戰／遠程／魔法攻擊（各一項） | 對應傷害 +2% |
| 近戰／遠程命中（各一項） | +1 個百分點 |
| DG | +1 個百分點 |
| AC | AC −0.5 |
| MR | +1 個百分點 |
| 攻擊速度／移動速度（各一項） | 對應速度 +2% |
| HP 回復 | +0.05 HP／秒 |
| MP 回復 | +0.025 MP／秒 |
| HP 成長／MP 成長（各一項） | 物種該項每級基礎成長 +1% |

共 14 項；個性不提供寵物原本沒有的攻擊模式。抽到目前用不到的遠程、魔法或 MP 成長項目時，依需求的全池抽取保留記錄，不偷偷換成更有利的屬性；這個結果需在確認畫面說清楚。

- 基礎常見：從池中抽一個正面項目。
- 進階單型：抽一個正面、一個負面；項目不能相同。
- 進階複合：抽兩個正面、兩個負面；四項互不重複。
- 負面效果反轉基準增量的方向，再乘負面倍率。例：AC 負面白色為 +0.5 × 1.2 = +0.6 AC，防禦變差。
- 主、副個性在各項累加後才套一次總係數；不互乘。命中與 MR 最後沿用原有上下限；自然 HP 回復仍遵守脫戰及飢餓限制。
- 不逐級抽成長。HP／MP 成長個性只改等級公式中的每級基礎增量，計算過程保留小數，最終最大值才取整。

建議層級機率：常見 88%、進階單型 11%、進階複合 1%。野生個性品質：白 70%、藍 27%、橘 3%。它們是新提案，不是已確認機率。

例：橘色常見「近戰攻擊」增加 2% × 1.5 = 3%；橘色進階單型若是近戰增益、移速減益，則近戰 +4%、移速 −2.8%。若副個性另有近戰 +2%，兩份合計 +6%，不是 1.04 × 1.02。

## 5. 忠誠、飢餓與死亡

建議忠誠 0–1000，捕獲／出生初值為 0。存活、同圖、正常出戰且食物至少 20 時，每累積 600 秒加 1；不足的秒數保存。飢餓、死亡或寄放時暫停，不抹掉零頭時間。

| 忠誠 | 額外最大 HP | 額外物理／魔法傷害 |
| --- | --- | --- |
| 0–99 | 0 | 0 |
| 100–399 | +0.5% | 0 |
| 400–999 | +1.5% | +1% |
| 1000 | +3% | +2% |

沿用食物最大 100、每 60 秒出戰時間減 1、專屬食物一次 +20。食物 1–19 停止累積忠誠但仍可戰鬥；0 時不攻擊、施法或自然回復。每次真正由活轉死扣 6 忠誠，最低 0；重複載入屍體、寄放、復活本身不再扣。

例：正常出戰約 16 小時 40 分鐘到第一個忠誠門檻；死亡扣除約一小時的累積。是否太慢是本提案特別需要試玩確認的地方。所有增益以「基礎值（+忠誠增益）」藍字呈現。

## 6. 繁殖、異色及先祖

### 繁殖資格與成本

- 父母必須同物種、異性、存活，且主人持有兩個不同項圈；在村莊寵物 NPC 操作。配種時先寄放兩隻，避免一隻寵物同時戰鬥和交易。
- 可用次數 = (等級至少 30 ? 1 : 0) + (等級至少 45 ? 1 : 0) − 已用次數。
- 建議 LV45 若從未繁殖，可連續使用兩次；不另外加每日冷卻。
- 建議初版不收金幣、不消耗父母項圈，成功各扣一次可用次數，產生一隻 LV1 子代及新項圈。合法配種必有子代，不另設繁殖失敗抽樣。
- 孩子初始食物 100、忠誠 0、滿 HP／MP、不出戰。性別各 50%。父母保留原狀，只記錄次數增加。
- 可選父母只來自本人持有的項圈；家庭成員各持一隻跨裝置配種及項圈交易需另外的雙方持久化交易流程，不能靠修改 tradeable 旗標冒充完成。

### 繼承與近親判定

只繼承父母的出生屬性 B；不繼承等級加成、裝備、忠誠、光環或暫時法術。每個屬性獨立抽一個 9000–11000 的整數：

子代 B = 父母 B 的平均 × 擲數 / 10000，向下保留四位小數。

屬性最低 1；不在物種初始 max 封頂。超過或等於 max 的該項品質為橘色，其橘色身份不因顯示捨入改变。父母共用項圈、相同個體、直接父母子女或共享任一父母者拒絕配種；不自行增加「所有遠祖都不能配」的限制。

每隻記錄永久譜系 ID、父母譜系 ID、四位祖父母譜系 ID，以及這些個體已保存的個性快照。譜系 ID 不沿用房內臨時 actor ID，項圈轉手也不重置。

### 個性遺傳

每個抽取項目的基礎權重為 1；父母任一主／副個性曾影響該項，該父／母各加 2 權重，最多 5。正面與負面均算「影響」，不保證照抄方向。依前述不重複限制抽項目。

每名父母以其主、副個性中的最高品質計分：白 0、藍 1、橘 2；雙親總分 S 為 0–4。子代個性品質機率建議：

- 白：70 − 5S %。
- 藍：27 + 3S %。
- 橘：3 + 2S %。

因此雙橘父母的子代品質機率為白 50%、藍 39%、橘 11%，仍可能生白色。這只作用個性品質，不干預出生屬性 ±10% 或先祖 1/32。

### 異色

建議野生異色率 1/4096。異色野生寵物隨機選一項出生屬性設為物種 max，其餘四項在各自區間上半部使用前述雙擲平均，至少藍色。性別及個性仍正常抽取。

子代異色率建議：雙親皆普通 1/256、單親異色 1/64、雙親異色 1/16。子代屬性完全依繼承公式，不因異色再額外疊一層數值倍率。異色是原美術的配色分支，不借用外部商用素材。

### 先祖血脈

每次合法出生獨立擲 0–31，為 0 時覺醒。主個性先按正常規則完成；副個性從父母與祖父母保存的個性記錄中等機率抽一份完整記錄，包括類型、品質、項目及正負效果。

只放入真實已有的祖先記錄，不補造不存在的祖父母。不同祖先持有相同個性時仍是不同記錄，因此各有一次抽取權重；主副相同也允許，仍依已確認規則直接相加。已完成 v4 遷移的父母至少各有一份個性，故正常配種不會出現空池。

覺醒者顯示金色「先祖血脈」，並分開列主、副個性效果。先祖機率不因 CHA、異色、忠誠或父母品質變動。

## 7. 舊寵物相容：不暗中重抽

推薦保留明確的 legacy 分支。已有寵物的四資質、個體／項圈／捕獲來源 ID、HP／MP、經驗、飽食、位置及計時器原樣保留；載入、匯入和進出家庭房間不抽新的屬性、性別或個性。舊寵仍可原樣戰鬥、寄放及復活。

若玩家要讓舊寵參加 v4 繁殖，先提供一次可取消的升級預覽，顯示前後能力，明確確認後才轉換：

- VIT 由舊 hp 資質、STR 與 INT 由舊 attack、DEX 由舊 speed、MND 固定取物種中點。映射比例分別為 (舊值−80)/40、(舊值−90)/20，套入新物種 min–max 後保留四位小數。舊 defense 另保存為 legacyDefence，不冒稱它原本就是 MND。
- 舊資料沒有性別／個性／譜系，不冒造既有血統。預覽讓玩家一次選擇性別及一個白色常見個性；選定後永久保存，不能取消存檔再換。
- 舊寵作為無已知父母的譜系創始者；不是捏造父母。繁殖次數從 0 開始，忠誠從 0 開始；普通原畫外觀保持普通，不重新抽異色。
- 用當前等級的舊 HP／MP 上限、攻擊、AC、MR、攻擊／移動間隔計算並保存固定校準差，使確認時的這些基礎數值不變；以後新增的等級成長、明選個性及忠誠按新規則計算。面板分列「舊版保留差」。
- 遷移不消耗世界 RNG、不補算過去忠誠、不增加繁殖次數，也不重新製造項圈。保存失敗整筆取消。

此方式保護既有培養成果，但需要一次明確升級操作；如果使用者希望所有舊寵自動轉換，必須先改定遷移規格，不能自行套用本段以外的抽樣。

## 8. 存檔與驗收門檻

採版本化 pet schema，保存出生屬性、各項品質、個性、忠誠整數／時間零頭、異色、性別、譜系、次數、寵物背包及必要計時器。舊版四資質的必填／上限規則只適用 legacy，不能為了讓 v4 過關而移除所有寵物校驗。

繁殖及舊寵升級使用已有預備／提交交易精神：先鎖定雙親、次數、RNG結果及子代資料並持久化，再單次提交；重複請求回同一結果。只有保存成功才顯示完成，斷線不重新擲先祖、異色或基因。家庭房內的成果同樣須進本人 checkpoint，不能等下一個普通自動保存才算成功。

必要回歸：

1. 十一物種的每項範圍、獨立生成、品質邊界及中間值能力；新生同種不同個體有差異。
2. 升級／分段／離線／保存重開結果一致；讀檔與 UI 不耗 RNG。
3. 餵食門檻、出戰容量、飢餓、死亡及復活；忠誠只累積一次，死亡只扣一次。
4. 親子與半血緣兄弟拒絕、LV30／45 邊界、重複提交及中斷恢復；父母項圈與子代唯一性。
5. 各屬性突破獨立橘色；先祖恆為 1/32 分支、主副效果相加、不捏造祖先資料。
6. 舊寵取消升級不變、確認遷移有封存、丟失租約不能提交；不能用旧驗證器匯回抹掉新資料。
7. 家庭房間對永久譜系 ID、背包物品及新計時器的映射／保存；項圈交易另驗證雙端中斷與重送。
8. 異色與金徽章維持原畫风、八方向、觸控與手機效能實測；程式有欄位不算視覺驗收完成。
