# 素材來源與授權狀態

專案沿用自行開發的瀏覽器引擎。現有美術的來源記錄為專案原創生成與後製的角色、地形、介面及特效，沒有以擷取官方遊戲 sprite 作為素材來源；音訊來源記錄為原創程序合成與編曲，不是原遊戲錄音。

重建文件不是遺失製作材料的逐位元恢復。現有可執行素材不等於所有原始生成輸入、來源大圖、製作工具或外部依賴都已隨附，也不保證可以完全重現原始製作流程。

## 畫面方向與驗收

維持精緻手繪／厚塗的整體風格。本次保留已接受的行走步態及重複腿部姿勢限制，仍列於後續改善。三個新怪物身體已完成實際綁定、来源方向／動作檢查與有限 E 場景的足底、接觸、施法飛行及恢復檢查。其他方向的實際接觸與原生裝置仍未全面驗收；素材存在不代表所有視覺門檻皆通過。

加入或替換素材時保留相對路徑、來源與改動紀錄；驗收證據須指向實際交付檔案及雜湊，不能把整份私人製作記錄放進儲存庫。

## 字型

介面字型 `dist/full/art/fonts/ashen-tc-text.woff` 來自 Noto Serif CJK TC。隨附來源記錄寫明：裁切為介面／資料文字子集，更名為 Ashen TC Text，字形未改；子集外玩家名稱使用系統字型備援。

來源是 [Noto CJK](https://github.com/notofonts/noto-cjk)，使用 SIL Open Font License 1.1。保留 [字型授權文件](../dist/full/art/fonts/LICENSE-Noto-CJK.txt)、[來源與修改說明](../dist/full/art/fonts/provenance.json)及字型本身。此授權不會自動成為整個儲存庫的授權。

## 規則與名稱

遊戲採古典斜視角 RPG 風格，部分名詞及數值參考既有遊戲或提供的來源表。來源確認與暫定設計應分別揭露，見 [TESTING.md](TESTING.md)；來源支持某個名稱，不等於也支持掉率、傷害公式、精確地圖或全部自訂規則。

顯示名稱、參考資料與原創美術不能被解讀成第三方官方授權、合作或背書。部分檔名、程式類別、資料庫與存檔格式保留 `Ashen Covenant`／`ashen-covenant`，源自專案先前名稱；保存格式與 ID 需維持相容，不應一律取代。

目前沒有為儲存庫整體選定通用開源 LICENSE，不自行套用 MIT、Apache、Creative Commons 或其他授權；已隨附的字型授權仍須遵守。不能從素材原創或儲存庫私人，推論第三方名稱／內容可任意公開散布、再授權或商用。

新增外部圖片、音訊、字型或程式時，逐項保留來源、原始授權、必要標示與修改紀錄；未釐清的權利明確列出，不以推測補足。
