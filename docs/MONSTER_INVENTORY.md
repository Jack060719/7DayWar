# 怪物盤點

本專案目前列冊 129 種怪物，包含原有126種與本階段新增3種；不是官方完整怪物總表，也不把NPC、玩家、寵物外觀另算成新怪。

兄長十二怪表中，九種本來已在catalog，本版更新其新生命素質／行為／掉落；新增物種只有哥布林、侏儒戰士、妖魔法師。十二同種新資料可在其既有各地圖生效，並非每張地圖都生十二種。

目前獨立怪物body綁定 128 份。未綁：黑暗精靈（MON-DARK-ELF）。綁定與像素完整性不等於所有方向接觸或手機實機已驗收。黑暗精靈原來源修復仍停留，沒有用其他暗妖替代。

銀騎新增77固定營地、215槽，保留48既有槽。其他村莊路線密度尚未完成，不能用全catalog數量代替遇怪節奏證據。
