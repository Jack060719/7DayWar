# 妖精持劍持盾候選

六動作、八方向，共 336 幀。使用原創 imagegen 編輯與透明輸出，原圖、prompt 與處理工作檔保留於 `../../elf-trial/`。

每方向全幀已在灰底檢查角色、左右手、盾牌與動作連續；每動作 `native-artifact-qa.json` 記錄真正 Chrome PNG/WebP 解碼、原時長、尺寸、透明邊界與雜湊。六組均無空幀、無任何 alpha 碰格邊。全組沿同一待機比例，只依 raw cell 解析度換算並平移足底；沒有逐幀縮放。

攻擊及死亡採不同原創生成的完整方向／幀段配對，具體來源記於各 `qa.json`，不假稱全部出自單張。死亡後段已補左盾、修正多餘右盾。NE／E 左臂在遠側時允許自然遮擋。原素材重複或微小的腿部動作保留。攻擊 NW 的含武器輪廓高度略高於原版，實際切換仍需在整合時查看。

這是可供 renderer 整合的素材候選，尚非手機或完整遊戲驗收。整合時沿用既有 attack contact、cast release、死亡延遲與所有 duration，勿以 staging manifest 取代原本的遊戲時序欄位。
