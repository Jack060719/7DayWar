# 存檔、升級與回退

角色保存在每個瀏覽器自己的 IndexedDB。靜態伺服器與 GitHub 資料夾不保存角色；交付包只能包含程式與合成測試資料，不能包含玩家真實存檔。

## 升級前保留兩樣東西

1. 在舊程式匯出原始 JSON，保留未修改的檔案。
2. 保留與該 JSON 相配的舊版完整程式包，以及版本或檔案雜湊紀錄。

只留其中之一不足以可靠回退。備份不要加入儲存庫，也不要讓新程式覆蓋唯一舊包。新程式有遷移封存機制，但仍應在升級前自行保留原始備份。

## 四角色帳本

舊單角色存檔會先封存，再升級為一份最多四名角色的帳本，原角色成為第一名。新增、切換、離線練功、匯出／匯入及故障復原都保存整份帳本，保留單一寫入者租約與 revision 檢查。進家庭房只更新選中的角色，其餘本機角色暫停；離房後繼續。舊單角色程式不能安全讀取四角色帳本，回退需使用真正升級前的程式與 JSON。

## 回到第二階段

第三階段已加入 `inventory.scrolls`／`storage.scrolls` 等新欄位。舊驗證器可能忽略陣列，顯示通過也可能看不到新版卷軸資產；不可直接把新存檔交給舊程式。

現行候選已有獨立的「恢復 Stage2 並停止」流程，並有受控工作階段與介面測試。操作時：

1. 先備份目前進度。選取真正的升級前 Stage2 JSON，確認匯入預覽允許恢復。
2. 使用「恢復 Stage2 並停止」入口，閱讀確認提示後才確認。它會先封存目前進度，再恢復選定快照；不合併升級後進度，也不補算備份至今的離線時間。
3. 成功後立即關閉所有遊戲分頁、停止伺服器，換回與快照相配的第二階段完整程式，再用原網址開啟。

**停止只作用於目前工作階段；不要重新整理仍在使用新版程式的頁面。** 新版重新載入可能再度遷移。此流程不是在新程式裡永久鎖定第二階段，也不會自動替換程式包。

具有圖鑑／變身契約的真正第二階段快照應走此專用入口，不能與更早的變身升級前回退混用。含第三階段新欄位／物品的狀態不應繞過保護。任何復原失敗都應保留原始備份，不可反覆建立新角覆寫。

2026-10-10 的受控儲存證據涵蓋封存、遷移失敗不覆寫、專用恢復與停止。2026-10-11 另以隔離 Chrome 設定檔實測真 IndexedDB、毀損原文／封存復原、Worker、兩分頁寫入保護及房間重載；6／6 通過。這仍不代表 Android／iPhone、斷電或裝置故障已驗收，範圍見 [TESTING.md](TESTING.md)。

## 家庭房間的保存（2026-10-11 候選）

每人仍使用自己的 IndexedDB。進房先保存單人基線，房主再建立新的共同世界；配對服務只管理記憶體中的房號及連線資料，不保存角色。房主收到的角色資料用於此次房間結算，不能當作你的雲端備份。個人歷史世界不傳給房主，始終保存在原裝置；寫入成果前由本機還原當次進房基線。

房主約每 2 秒送出個人成果 checkpoint；融合、突破、附魔、寵物等不可重抽操作要求立即保存；交易另有雙方暫鎖與房主保存決定的流程。每個 checkpoint 都必須通過角色身分、原單人世界、原位置、時鐘／RNG、寫入權、revision 與序號檢查。只有成功寫入本機 IndexedDB 的進度才是已保存成果；房間畫面快照不能直接當成單人存檔寫入。

正常選「保存並離開房間」會嘗試最後保存，回到進房前的單人地圖與位置，帶回已保存的角色成長、裝備、物品消耗及任務成果。原單人世界不會被房間怪物覆蓋；效果計時會換回原單人時鐘。未拾取掉落與房間召喚物留在房間。

房主失聯、配對程序重啟、切換背景或頁面被關閉，可能使房間結束。突然中斷只能保留最後成功寫入的 checkpoint，不能保證最後畫面上的操作都已保存。再次開啟若看到「上次連線已結束」，可先匯出已保存進度，再按「繼續單人遊戲」；系統不會把未確認房內時間重新當成離線狩獵計算，也不會自動接回舊房間。

房內禁止新建、匯入與切換存檔；管理個人存檔前先離房。訊息超過 4 MiB 或加入資料無法送出時會拒絕／退出連線並保留單人進度，不以刪減欄位繞過校驗。完整操作與部署說明見 [FAMILY-ROOMS.md](FAMILY-ROOMS.md)。

## 交易中斷與暫鎖物品

尚未雙方確認同一版本內容就斷線，交易取消、不交換。開始最後保存後中斷，相關物品暫鎖，重新連到原房主角色後依其持久保存的決定完成或退回。背包會顯示提示，其他資產與本機角色仍可遊玩。

帳本中任何角色仍有暫鎖交易，或房主還有未完成的參與者保存確認時，不能直接匯入舊備份或回復舊程式來清掉紀錄。仍可匯出完整備份；請先回原房主核對。故障復原若能讀到已校驗的未結交易紀錄，只接受保留該紀錄的候選。這套保護不等於雲端備份，也不提供公開競技防作弊。

## 換網址、裝置或瀏覽器

- 從原環境匯出 JSON，到新環境檢查後匯入。網址、IP、通訊協定或連接埠不同就可能使用不同儲存來源。
- 不要長期使用無痕模式；清除網站資料前先備份。
- 本機存檔不自動同步，請定期匯出到自己的安全位置。
- 報錯提供版本、錯誤訊息與合成重現案例，避免提交真實角色檔。

存檔鍵、資料庫與內部格式保留部分 `ashen-covenant` 名稱是相容需求，不應因顯示名稱改變而更名。
