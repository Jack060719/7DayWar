# Stage3 缺口：已確認的試玩規則

日期：2026-10-11。使用者已逐組確認 P1～P5 作為試玩初版，另明確同意四角色整份帳本的封存升級方案。這是已批准的規則，**不是全部已實作或驗收完成的清單**，也不是原作官方數值。

## 已確認，實作中

- 每台手機最多四名角色，可各自設定自動狩獵或同圖組隊，切換其中一人操作；舊存檔為第一角。家庭房只帶選中的一角，其餘三角暫停，離房後接續。
- 家庭最多十支手機。新房間世界，帶入角色與裝備、保留個人任務；離房回原本位置並保留已保存成果。房主離開／斷線先保存已確認成果再結束，不轉移房主。
- 參戰資格：本人／寵物／召喚物攻擊（含未命中），或實際替參戰者補血；參戰後死亡或換圖保留，離房移除。
- 家庭經驗均分、每堆物品隨機分一人；Boss 保證每名參戰者有一般戰利品。整隊總經驗／掉落乘人數倍率，**不是每人的掉落各乘倍率**。
- 倍率：1 人 1、2 人 1.5、3 人 2.5、4 人 3.5、5 人 4.5、6～10 人 5。首次開戰以同地圖房員數鎖定，直到該怪死亡；增加血量、攻擊、物理防禦。魔防、命中、攻速和移速原值保留。現有 AC 防護量以 10−AC 計算，再乘倍率換回 AC。
- 項圈重量 0；有效寵物魅力＝基礎＋裝備＋隱藏值（妖精 12、法師／黑妖 6、騎士 0），供容量與野生捕捉。最後参戰後 8 秒內不自然回血；藥水與魔力回復原規則保留。

## P1：技能學習與突破

建議第一次學習符合職業、等級與地點即 100% 成功，消耗一本書／一顆水晶。一般及法師魔法須在正義或邪惡神殿兩格內；妖精精靈魔法在母親樹兩格內；黑妖技能不限制地點。騎士現有技能保留，缺少名稱的「後期新技能」須另給名單。

重複讀同一本書嘗試突破；失敗只消耗該書，不扣既有突破次數。n 表示已成功次數：

- 下一次成功率＝10% ÷ (1＋n÷10)。0／10／30 次成功時，下一次成功率分別為 10%／5%／2.5%。
- 傷害、治療或正面效果時間總增幅＝20% × n÷(n＋20)。1／10／20 次成功分別約 +0.95%／+6.67%／+10%。
- 適合省魔的技能，耗魔總減幅＝10% × n÷(n＋20)，耗魔向上取整，原本有耗魔者至少 1 MP；不減材料、HP 或冷卻。
- 每招只強化一個方向：有直接傷害優先傷害；否則有直接補血優先治療；否則有正面限時效果優先時間；其餘採省魔。控場命中率、即死率、召喚數及融合成功率不受突破增加。
- 成功次數無玩法上限，成功率與每次增幅逐漸下降。藍色括號顯示實際加值；沒有立即受益的招式須在書本確認畫面清楚說明，不默默吃書。
- 舊角色全部從突破 0 開始，不改已學技能、不重抽既有結果。

## P3：附魔 v2.2

武器有一個元素軌與一個特效軌；頭、甲、斗篷、手套、鞋、盾／臂甲只有元素軌。飾品不附魔。每次使用一顆對應石頭，失敗只消耗石頭。與既有 +N 融合完全分開。

| 項目 | 建議數值／規則 |
| --- | --- |
| 四元素石來源 | 依怪物現有自然元素，普通怪每次擊殺 0.5%；自然屬性 none 不掉元素石 |
| 五特效石來源 | 菁英 2%、Boss 10%；成功掉石後五種均勻抽一種 |
| 附魔成功率 | 該軌已有 n 次成功，下一次為 50% ÷ (1＋n÷5)，初次 50%、5 次後 25% |
| 武器元素 | 成功 n 次增加對應元素傷害 10n÷(n＋10)；首次約 +0.91、十次 +5，計算最終傷害才取整 |
| 防具元素 | 每件增加對應元素抗性 15n÷(n＋10) 個百分點；十次 +7.5，沿現有元素抗性減傷與 80% 上限，不重複另算一次減傷 |
| 特效觸發 | 成功 n 次後，物理命中觸發率 10n÷(n＋10)%；十次約 5%，一次普通攻擊每軌至多一次 |
| 吸血／吸魔 | 成功觸發時取實際造成傷害的 10%，向下取整但至少 1；吸魔不超過對方當下 MP，回復不超過自己上限 |
| 麻痺 | 1 秒；同一目標此附魔控制至少間隔 8 秒，沿用免疫規則 |
| 緩速 | 移動／攻擊間隔 +20%，3 秒；不疊倍，只延長至較晚到期時間 |
| 破甲 | AC 增加 2（防禦降低），5 秒；同種不疊層 |
| 換屬性／特效 | 明確確認後，成功才換掉該軌舊效果；沿用該軌累積成功次數，不能用換屬性重置低難度；失敗舊效果保留 |

附加元素段只出現在原物理攻擊命中後，走現有魔防／元素抗性公式；不改原物理傷害。不再用附魔觸發附魔，避免連鎖循環。武器元素與特效可各自換種，不互相覆蓋。

融合：只有一邊有該軌附魔就完整保留；兩邊皆有則在預覽逐軌選保留哪一邊，保留該邊種類與成功次數，不相加、不重抽。預備交易、提交、保存、中斷重開使用同一份已封存選擇。藍色括號列實際效果；火紅、水藍、風綠、地黃只影響呈現。

## P4：全圖營地、趕路及城鎮

這一組已確認加入試玩。眼前的全圖既有怪物「視野內不重生」修正，不等於已完成本組密度。

- 新手密度 10～12 格：銀騎新手路帶、說話之島及古魯丁一樓。一般 6～10 格：妖森／風木／海音／歐瑞／亞丁一般野外與未列危險的地下 1～3 樓。危險 4～8 格：龍之谷、火龍窟、風龍窟、黃昏山脈、遺忘之島、傲慢之塔與其餘深層地下。城鎮不新增敵怪；原本銀騎高階區保持危險。
- 營地先用該棲地既有物種，3 隻一組；守點兩隻、沿可行走路線短巡邏一隻。不把不相干物種搬到其他地區。
- 一組清空後滿 90 秒，且整個營地離開所有同圖角色視野才一起補下一代；未清空不補個別成員。保留槽位、自然生命世代及已確定期限，不補在牆、水、地圖外或封閉無路格。
- 無視奔跑：不主動停下攻擊，持續前往目的地，可喝藥／自保。順路清怪：只清目前路徑前兩格內的敵怪，或正在攻擊自己的怪；不偏離路線去清其他怪，結束後接原目的地。
- 缺藥或負重達 80% 使用回城卷；最近村莊按當前可通行步行路徑的總格數，排除船程與無權限路線。沒有回城卷則告警停下自動狩獵，不假裝已返城。
- 妖森非妖精通行證：在銀騎服務 NPC 支付 1,000 金幣取得該角色永久許可；妖精免許可。先提供取得途徑，才啟用限制，不將舊角色關在無法離開的地點。
- 銀騎入門裝備：匕首 100、短劍 300、弓 300、法杖 300、皮甲 200、小盾 150、皮帽 100、皮手套 100、靴 100 金幣；全為已鑑定普通 +0。新手初始禮包不變。
- 跨海趕路：抵港後使用現有船班與票价；缺錢或無票就停在港口並提示，不免費瞬移。

使用者另確認怪物配合：近戰同族攔截追擊後排的玩家；弓手／法師找可走格退開、保持射程；已有控場技能的怪優先控制追擊後排者。不新增傷害或治療數值；新增補血技能留待另行確認。未提供規格的敵對血盟／紅名 PvP 不會自動加进家人合作房。

## P5：菁英、祝福掉率、友方變身及交易

- 菁英建議採「既有普通怪的菁英個體」，不整批改原物種分類：一般棲地新生個體 2% 機率；HP×2、攻擊×1.25、物理防護量×1.25、EXP×2。Boss 不再變菁英，舊存活怪不追套。
- 菁英擊殺後 2% 機率直接永久解鎖該物種變身，不生成菁英卡片；普通擊殺累計與既有 Boss 契約規則保留。
- 裝備掉出後成为祝福的機率，建議普通 0.5%、菁英 2%、Boss 5%；這是新的平衡提案，會取代目前部分新怪暫定 10%，只在新生個體使用新規則，舊存活個體保持其原規則。
- 友方變身：施法者選目標，再選目標已解鎖的形態；友方目標允許／拒絕後才扣 MP／魔石並施法。禁止對怪、寵、召喚物施放；自己施放不需邀請。離房、死亡、距離變化或拒絕會取消。
- 實際交易建議先做同圖三格內的雙方交易窗：可交換金幣、可交易物品、Boss 契約及已收回的項圈。雙方各自確認最終內容，任一方改內容就清除雙方確認；由同一權威結算一次。對方背包放不下、項圈寵物仍出戰、物品投入融合、有人離房或中斷時不扣除。只標記 tradeable:true 不算完成交易。
- 使用者另確認交易中斷處理：尚未雙方確認就中斷，取消且不交換；最後保存途中中斷，將本筆物品與金幣暫鎖，重連原房主後依其持久決定完成或退回。其餘物品與角色可照常遊玩，暫鎖資產不得花用或重複交易。
