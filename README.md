# 七日戰線 / 7DayWar

「七日戰線 / 7DayWar」是繁體中文、固定斜視角的瀏覽器 RPG，可各自單人遊玩，也可使用家庭連線候選一起冒險。這份儲存庫包含可直接修改的遊戲程式、現有素材、合成測試與開發文件。

**本次版本：7DW-20261016-01（改名與密碼入口；延續第三階段試玩版）。** 加入本機四角色、手機房主共同世界、橫向介面、技能突破、寵物 v4、附魔、世界營地與雙方確認交易。15 套持盾／無盾動作配對已接入，裝卸盾會切換外觀。已做 Windows Chrome 原生瀏覽器驗證，Android／iPhone、公開部署及新版 ZIP 尚未驗收；詳見 [測試說明](docs/TESTING.md)。

每部裝置最多保存四名角色，可選騎士、妖精、法師、黑暗妖精；控制一名，其餘依各自設定練功或同圖組隊。家庭房間常態 2–3 人、最多 10 人含房主，需同一 Wi-Fi、HTTPS 遊戲網址及配對服務；每人保留自己的角色與存檔。進家庭房只帶選中的一名，其他本機角色暫停；雲端存檔同步不在本版範圍。 單獨提供靜態網址不會自動建立共同世界。

這是持續開發的自製專案，並非官方遊戲客戶端。部分資料是已確認來源，其他數值是明列的暫定設計；不宣稱完整還原任何商用遊戲版本。

## 名稱與遊玩入口

遊戲入口與備份檔名使用「七日戰線 / 7DayWar」。首次遊玩輸入 `7day`；同一網站、同一瀏覽器以本機標記記住通過結果，清除網站資料、無痕或儲存被阻擋時可能需要重輸。這是公開靜態網站的進入提示，不能保護公開程式與素材，也不是多人伺服器的身分驗證。存檔鍵、格式與角色 ID 保持相容；舊備份不需改名。

網站方向改為 **GitHub Pages 提供網頁與素材，Windows 電腦負責未來多人世界**。目前多人仍是房主瀏覽器結算，電腦統一結算尚待實作；Android 完整 APK、iPhone 完整離線 PWA 也不因改用 Pages 自動完成。四角色與既有玩法維持。部署流程見 [PUBLISHING.md](docs/PUBLISHING.md)。

## 啟動

先完整解壓縮資料夾，安裝 Node.js；2026-10-11 的驗證環境為 `v24.20.0`。Windows 可雙擊根目錄 `START-LOCAL.cmd`。其他系統在根目錄執行：

```sh
node portable/server.mjs --root ../dist
```

接著開啟 `http://localhost:8080/full/`，並保持終端機開啟。停止伺服器使用 Ctrl+C。

伺服器已支援 `--root`；相對路徑以 `portable/server.mjs` 所在資料夾為準。這份儲存庫使用唯一的 `dist/`，所以需帶 `--root ../dist`。省略參數時保留舊便攜包的 `portable/site/` 預設，但本儲存庫不另附重複的 `site/`。

目前沒有 `package.json`、第三方 npm 套件或必要的 npm 安裝／建置步驟。`dist/full/` 就是可編輯的現行程式，沒有另一份 `src/` 可重新產生全部內容。

電腦與手機單人測試見 [GETTING_STARTED.md](docs/GETTING_STARTED.md)。家庭開房、配對服務命令及 HTTPS 部署條件見 [FAMILY-ROOMS.md](docs/FAMILY-ROOMS.md)。若網站與配對服務仍由你的電腦提供，電腦必須保持開機；兩者另行託管後才不依賴它。本次尚未選平台、付費或發布。Windows `.cmd` 與 iPhone／Android 實機仍待驗收。

## 已有功能與本階段機制

既有功能包括四職創角、單角色移動與尋路、地圖切換、戰鬥、NPC 服務與任務、技能書與技能、裝備／行囊／倉庫、基礎寵物、自動狩獵、離線結算，以及本機保存、JSON 匯出匯入及封存恢復。

2026-10-11 已確認試玩規格：

- 每次開房建立新世界，共享怪物與戰鬥；本人／同伴攻擊及實際治療既有參戰者皆計資格，經驗均分、普通掉落隨機分物，Boss 保證每位參戰者有一般戰利品；家庭人數增加怪物血量／攻擊／物理防禦及全隊總獎勵，上限五倍。
- 本機四角色整份帳本保存、離線結算與切換；技能突破、元素／特效附魔、寵物 v4 成長與繁殖、寵物背包、交易與友方變身同意。舊寵物須逐隻確認升級；數值依已採用的試玩提案。
- 地區密度、三隻營地、整組清空 90 秒且離開所有人視野才補怪；旅行可選直接奔跑或順路清怪，新增通行證與入門裝備商。
- 約每 2 秒保存個人成果；離房回原單人位置，房主中斷即結束房間，重開保留已保存成果且不重算未確認房內時間。
- 橫向介面將血魔資訊放左上、快捷列靠下、功能按鈕靠右，縮小固定黑欄並保留原美術；處理長姓名、觸控尺寸與安全區。
- 毀損存檔原文匯出與確認復原、Worker／寫入權保護、死亡怪物停止行動、建築快取更新，以及 `/full` 導向與 Opus MIME 修正。

2026-10-10 第三階段候選已有：

- 十二種怪物的版本化定義、72 個來源數值與 60 組來源掉落對應。新生定義只套用原本有該物種的地圖；舊活怪保留原定義直到自然重生。
- 銀騎固定營地、視野外補怪、新角色補給與投餵門檻。營地政策只限銀騎，不等於全世界密度已調整。
- 新道具、獨立卷軸個體、融合預覽與交易保存／恢復；既有角色不追發新角物資。
- 妖魔法師開始施法時扣 MP 的單體火球、低 MP 時法杖攻擊、有限野怪復活、指定深地監卷軸來源及祝福裝備效果。
- 升級前快照封存，以及需使用真正升級前 JSON 的「恢復 Stage2 並停止」流程。

這些是目前程式與有範圍的測試覆蓋，不代表全部互動、平衡、動畫或裝置已完成驗收。候選中仍有暫定機率與數值，詳見 [測試與規則狀態](docs/TESTING.md)及 [本版自設值](dist/full/silver-disclosure.json)。

## 已知限制

- 專案列冊129種怪物；黑暗精靈本次重用專案既有的原創 FI 弓手身體，未新增獨立美術。來源、8 向動作與變身檢查見 [素材重用記錄](docs/art/dark-elf-reuse.md)。三隻新怪是十二怪表中原先缺少的哥布林、侏儒戰士、妖魔法師；不是整個遊戲只有三隻怪。詳見 [逐種與各地圖清單](docs/MONSTER_INVENTORY.md)。
- 三新怪已有有範圍的E方向根部、接觸／施法飛行與回復畫面檢查；其他方向接觸及真實裝置仍未逐一驗收。
- 保留精緻手繪／厚塗的整體方向。部分行走步態及重複腿部姿勢是本次已接受保留的限制，後續仍可改善。
- 銀騎路線實際遍歷 18 向中有 16 向到達，路線 6 正反兩向在高等測試角色紅水耗盡後死亡，屬既有高等怪區域的生存限制；不能宣稱所有方向都能安全走完。
- 新增 47 個物品／卷軸／契約圖示；附魔石使用既有原創寶石圖加元素標示。全世界長期平衡及完整原作還原仍待持續驗收。
- 四角色、寵物 v4 與 P1–P5 已接入試玩規則；逐項範圍見 [需求對照](docs/STAGE3-COMPLETION.md)。家庭連線仍待手機驗收，房主需保持前景；公開競技／帳號系統不在範圍，不支援房主轉移。
- iPhone／Android 版面、觸控、音訊、前後景恢復與長時間效能尚未實機驗收。桌面 Chrome 的多分頁／多設定檔測試不能替代 10 支手機驗收；完整離線安裝與無網際網路開房尚未完成。

工作順序及完成條件見 [ROADMAP.md](ROADMAP.md)。

## 資料夾結構

- `dist/full/`：完整內容版本的實際程式與素材；入口為 `index.html`。
- `dist/` 根目錄：保留的舊版入口與相關程式。
- `portable/server.mjs`：無第三方相依的唯讀靜態伺服器。
- `portable/signaling.mjs`：獨立的房間配對服務，只在記憶體保留配對資料；不保存角色。
- `START-LOCAL.cmd`、`START-LAN.cmd`：Windows 啟動入口。
- `tests/full/`、`tests/portable/`：引擎、畫面契約、保存與伺服器測試。
- `tests/browser/`：使用隔離設定檔與合成角色的原生 Chromium 測試。
- `tests/fixtures/`、`tests/helpers/`：配套來源表、合成案例與第二階段程式比較基準。
- `evidence/`：可隨包檢視的去識別驗證摘要，記錄覆蓋範圍及未完成項目。
- `docs/`：啟動、測試、存檔、推送與來源說明。

素材已預先備妥；本交付不承諾能由未附的生成輸入或製作工具重新產生所有素材。

## 存檔安全

**升級前保留原始 JSON 與相配的舊版完整程式包；回退必須兩者成對。** 舊驗證器可能忽略新版卷軸陣列，即使通過也不等於可安全降版。

存檔在每個瀏覽器的 IndexedDB，並不在這個資料夾。家庭配對服務不提供雲端備份；房間畫面快照也不等於已保存成果。更換網址、IP、通訊協定或連接埠會改變儲存來源。操作與回退風險見 [SAVE_SAFETY.md](docs/SAVE_SAFETY.md)。交付包不得包含玩家真實存檔。
