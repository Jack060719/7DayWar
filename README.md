# 天堂夢想版 / Lineage Dream

`lineage-dream` 是繁體中文、固定斜視角的瀏覽器單機 RPG。這份儲存庫資料夾包含可直接修改的遊戲程式、現有素材、合成測試與開發文件，供持有人自行推送至私人儲存庫 `Jack060719/lineage-dream`。

**本次版本：SP-STAGE3-20261010-01（單人怪物更新候選）。** 已接入本版怪物規則、三種新身體及有範圍的場景驗證；這不是全部兄長提案或全世界怪物／密度都完成。測試與實機未測範圍見 [測試說明](docs/TESTING.md)。

目前一次執行一名角色，可選騎士、妖精、法師、黑暗妖精。**四角色同時練功尚未完成；沒有多人共同世界或雲端存檔同步。** 多個人打開同一靜態網址，仍各自使用自己的瀏覽器存檔。

這是持續開發的自製專案，並非官方遊戲客戶端。部分資料是已確認來源，其他數值是明列的暫定設計；不宣稱完整還原任何商用遊戲版本。

## 啟動

先完整解壓縮資料夾，安裝 Node.js；目前程式檢查環境為 `v24.19.0`。Windows 可雙擊根目錄 `START-LOCAL.cmd`。其他系統在根目錄執行：

```sh
node portable/server.mjs --root ../dist
```

接著開啟 `http://localhost:8080/full/`，並保持終端機開啟。停止伺服器使用 Ctrl+C。

伺服器已支援 `--root`；相對路徑以 `portable/server.mjs` 所在資料夾為準。這份儲存庫使用唯一的 `dist/`，所以需帶 `--root ../dist`。省略參數時保留舊便攜包的 `portable/site/` 預設，但本儲存庫不另附重複的 `site/`。

目前沒有 `package.json`、第三方 npm 套件或必要的 npm 安裝／建置步驟。`dist/full/` 就是可編輯的現行程式，沒有另一份 `src/` 可重新產生全部內容。

手機的可信任家用網路啟動方式見 [GETTING_STARTED.md](docs/GETTING_STARTED.md)。Node 伺服器測試通過，不代表 Windows `.cmd` 與 iPhone／Android 實機已驗收。

## 已有功能與本階段機制

既有功能包括四職創角、單角色移動與尋路、地圖切換、戰鬥、NPC 服務與任務、技能書與技能、裝備／行囊／倉庫、基礎寵物、自動狩獵、離線結算，以及本機保存、JSON 匯出匯入及封存恢復。

第三階段候選已重新接入：

- 十二種怪物的版本化定義、72 個來源數值與 60 組來源掉落對應。新生定義只套用原本有該物種的地圖；舊活怪保留原定義直到自然重生。
- 銀騎固定營地、視野外補怪、新角色補給與投餵門檻。營地政策只限銀騎，不等於全世界密度已調整。
- 新道具、獨立卷軸個體、融合預覽與交易保存／恢復；既有角色不追發新角物資。
- 妖魔法師開始施法時扣 MP 的單體火球、低 MP 時法杖攻擊、有限野怪復活、指定深地監卷軸來源及祝福裝備效果。
- 升級前快照封存，以及需使用真正升級前 JSON 的「恢復 Stage2 並停止」流程。

這些是目前程式與有範圍的測試覆蓋，不代表全部互動、平衡、動畫或裝置已完成驗收。候選中仍有暫定機率與數值，詳見 [測試與規則狀態](docs/TESTING.md)及 [本版自設值](dist/full/silver-disclosure.json)。

## 已知限制

- 專案列冊129種怪物，128種已有獨立body綁定；黑暗精靈原來源仍待修復。三隻新怪是十二怪表中原先缺少的哥布林、侏儒戰士、妖魔法師；不是整個遊戲只有三隻怪。詳見 [逐種與各地圖清單](docs/MONSTER_INVENTORY.md)。
- 三新怪已有有範圍的E方向根部、接觸／施法飛行與回復畫面檢查；其他方向接觸及真實裝置仍未逐一驗收。
- 保留精緻手繪／厚塗的整體方向。部分行走步態及重複腿部姿勢是本次已接受保留的限制，後續仍可改善。
- 銀騎路線實際遍歷 18 向中有 16 向到達，路線 6 正反兩向在高等測試角色紅水耗盡後死亡，屬既有高等怪區域的生存限制；不能宣稱所有方向都能安全走完。
- 獨立道具圖示、其他村莊城外路線密度、全世界平衡及完整原作還原仍有缺口。
- 四角色同練、完整寵物 v4、多人系統與其他後續提案尚未完成。
- iPhone／Android 版面、觸控、音訊、前後景恢復與長時間效能尚未實機驗收。手機經 LAN 開啟時仍需 Windows 靜態伺服器運作；Windows 關閉後可獨立重開的完整離線安裝尚未完成。

工作順序及完成條件見 [ROADMAP.md](ROADMAP.md)。

## 資料夾結構

- `dist/full/`：完整內容版本的實際程式與素材；入口為 `index.html`。
- `dist/` 根目錄：保留的舊版入口與相關程式。
- `portable/server.mjs`：無第三方相依的唯讀靜態伺服器。
- `START-LOCAL.cmd`、`START-LAN.cmd`：Windows 啟動入口。
- `tests/full/`、`tests/portable/`：本次恢復後重新建立的測試。
- `tests/fixtures/`、`tests/helpers/`：配套來源表、合成案例與第二階段程式比較基準。
- `evidence/`：可隨包檢視的去識別驗證摘要，記錄覆蓋範圍及未完成項目。
- `docs/`：啟動、測試、存檔、推送與來源說明。

素材已預先備妥；本交付不承諾能由未附的生成輸入或製作工具重新產生所有素材。

## 存檔安全

**升級前保留原始 JSON 與相配的舊版完整程式包；回退必須兩者成對。** 舊驗證器可能忽略新版卷軸陣列，即使通過也不等於可安全降版。

存檔在每個瀏覽器的 IndexedDB，並不在這個資料夾。更換網址、IP、通訊協定或連接埠會改變儲存來源。操作與回退風險見 [SAVE_SAFETY.md](docs/SAVE_SAFETY.md)。交付包不得包含玩家真實存檔。
